# أيقونات التطبيق (PWA Icons)

المكان: `front/public/icons/`

الملفات المطلوبة (ضِف الصور بنفس الأسماء دي بالظبط عشان تشتغل من غير أي تعديل تاني في الكود):

| اسم الملف               | المقاس  | الاستخدام                                                                                                                           |
| ----------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `icon-192.png`          | 192×192 | أيقونة Android على الشاشة الرئيسية                                                                                                  |
| `icon-512.png`          | 512×512 | أيقونة Android الكبيرة / شاشة splash عند التثبيت                                                                                    |
| `icon-512-maskable.png` | 512×512 | نسخة "Maskable" لأندرويد (لازم يكون فيها padding/safe zone حوالي 20% من كل جانب عشان النظام يقدر يقصها بأي شكل بدون ما يقطع اللوجو) |
| `apple-touch-icon.png`  | 180×180 | أيقونة iPhone/iPad عند "Add to Home Screen"                                                                                         |

`icon.svg` (موجود بالفعل) فاضل زي ما هو ومستخدم كـ favicon وكـ fallback أساسي — مش هيتأثر لو اتأخرت في إضافة باقي الصور.

## ملاحظات مهمة

- الصور دي مش موجودة حاليًا، وده **متعمّد ومش هيكسر الـ build ولا الموقع** — المتصفح ببساطة هيتجاهل أي أيقونة الملف بتاعها مش موجود ويستخدم `icon.svg` بدلها لحد ما تضيف الصور.
- لو عايز تغيّر الأسماء أو الأماكن، عدّل بس في:
  - `front/public/manifest.webmanifest` (مصفوفة `icons`)
  - `front/index.html` (وسوم `apple-touch-icon`)
  - `front/vite.config.js` (مصفوفة `includeAssets` في إعداد `VitePWA`)
